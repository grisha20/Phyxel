# Phyxel

Phyxel — ранний прототип двумерной GPU-песочницы. Материалы описываются JSON-файлами, получают непостоянный `RuntimeIndex` при запуске, а клеточная физика, температура, фазовые переходы, горение и рендеринг выполняются compute-шейдерами DirectX 11.

Сейчас реализованы:

- общая физика granular, liquid, gas, movable solid и fixture;
- внешние материалы без пересборки игры;
- температура, теплопередача и ручной температурный инструмент;
- data-driven переходы `water ↔ ice ↔ steam`;
- дерево, древесный и каменный уголь, огонь, дым и CO₂;
- независимое от FPS охлаждение пара и перераспределение газов по плотности;
- краткая вспышка/давление пороха и тепловое тушение охлаждённого пламени;
- горючее масло и медленная пропитка древесного угля отдельным запасом топлива;
- избирательные фильтры для пара, воды, масла, классов частиц и выбранного вещества;
- сохранения v17 и загрузка старых сцен v3–v16.

Проект написан на C#/.NET 8 for Windows и использует KNI, DirectX 11 и HLSL. Это рабочее ядро, а не законченная игра: полноценная система произвольных реакций, разрушение от взрывов, пакеты контента, магазин и сетевой hub пока не реализованы.

## Быстрый запуск

Нужны Windows, .NET 8 SDK и видеокарта с DirectX 11.

```powershell
dotnet build Phyxel.sln -c Debug --nologo
dotnet run --project Phyxel.csproj -c Debug
```

Готовая Debug-сборка запускается из `bin/Debug/net8.0-windows/Phyxel.exe`.

## Фильтры

Откройте вкладку «Фильтры» снизу или кнопку «Фильтр» слева.
Каждая карточка — отдельная кисть со своим рисунком: только пар, вода,
масло, все газы, жидкости, порошки, выбранный вид, стенка, только воздух
и без воздуха. Наведение показывает пояснение; колесо/стрелки прокручивают
список. Справа показана выбранная кисть, кнопки перебора режимов больше нет.

ЛКМ рисует только в свободных клетках: частицы и существующие фильтры
не заменяются. ПКМ снимает слой; обычный ластик удаляет слой и частицы.
Чтобы заменить фильтр, сначала снимите его. Карточка вещества выбирает
обычную кисть; для точного фильтра затем нажмите «Выбранный вид».

«Только воздух» пропускает фоновый воздух/O₂, задерживая все частицы.
«Без воздуха» пропускает все частицы, включая подвижные тела, и блокирует
фоновый воздух/O₂. «Стенка» задерживает оба канала. Тепло проходит через
все варианты. Загруженная или сконденсировавшаяся внутри фильтра частица
сохраняется. Электрические и прочие устройства TPT отложены; класс
энергетических частиц для ENERGY WALL пока отсутствует.
[Проверки кистей](docs/FILTER_BRUSHES_RESULTS.md),
[проверки переноса и ограничения](docs/FILTERS_RESULTS.md).

## Сохранение сцен

«Сохранить» — выбрать файл; `Ctrl+S` — быстро сохранить в последний
выбранный файл текущего запуска; `Ctrl+Shift+S` — выбрать другой.
«Загрузить» или `Ctrl+L` — открыть сцену. Путь и результат видны внизу.
Сцена состоит из двух соседних файлов: `.json` и `.world`; переносите оба.
[Проверки и ограничения](docs/SCENE_FILES_RESULTS.md).
