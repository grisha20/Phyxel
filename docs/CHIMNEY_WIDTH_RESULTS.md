# Поток по ширине трубы —2026-10-04

Последующее исправление свободного факела: [FW](FREE_FLAME_RESULTS.md).
Текущий код ограничивает дополнительную дисперсию твёрдыми поперечными
стенками;6/6 печных случаев и ширина25.2–28.6/31 повторно PASS.
Ниже сохранены измерения первоначального CW-этапа.

Выбранный этап завершён: расширен физический поток без снижения продольного
отклика. Итоговая печная матрица и связанные проверки выполнены; один старый
сбой факела под широкой плитой в Simulation остаётся отдельно зафиксированным.
[Контракт до физики](materials/shared/CHIMNEY_WIDTH_CONTRACT.md).

## Что изменено

- Carrier читается плавно по четырём видимым узлам; fine-геометрия запрещает
  чтение через металл/жидкость. Старый nearest-node fallback только когда
  нет доступных узлов интерполяции.
- Потолочный обход сохраняет касательную скорость и снимает заблокированное
  нормальное смещение. Старый fixed.9 escape Sandbox остаётся лишь в почти
  неподвижном воздухе, magnitude<.05; движущийся carrier не заменяется им.
- Общая газовая дисперсия направлена поперёк carrier: zero-mean uniform,
  amplitude`min(1.5,1.5*speed)`, логический60Гц тик. Продольный coupling,
  буйность, Diffusion, предел7.2 и lifecycle прежние. Никаких добавочных
  частиц, pressure/heat sources или визуальной дорисовки не вводится.

Это ограниченная игровая модель неразрешённого смешивания, не CFD и не
баланс турбулентной/кинетической энергии. В TPT FIRE/SMKE Diffusion0;
Phyxel dispersion не выдаётся за скопированный коэффициент TPT.
TPT collision fallback умножает обе скорости на Collision; сохранение
tangent здесь — выбранная модель Phyxel. Версия exe TPT относительно
локальных исходников не установлена, «лучше TPT» не доказано.
