## Балансы и сохранение

hsolid=.13*T+p, hliquid=.50*T+p; L выбрано для нулевого reference.
Mass неизменна, p переносится с клеткой. Фазовое превращение не меняет
кислород. Два режима используют одну фазовую модель; только топливо
вокруг отличается расходом O₂. Writer17/Grid56/Material244 сохраняются;
палитра ID remap обеспечивает старые сцены. Пауза/частичное плавление/
сохранение/возврат своего ID прошли MA03; Writer/ABI не менялись.
