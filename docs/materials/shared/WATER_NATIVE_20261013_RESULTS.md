# W13 — первый этап оптимизации воды на100%, 2026-10-13

**Частичный результат.** Полный compute Sandbox уменьшился на8.3% при
заливке пустого поля и на12.1% при заливке ванны. Цель≥15% в обоих
сценариях **FAIL**, цель≥30% для фаз56/57 тоже не достигнута. Стабильные
100FPS и исправление всех просадок не заявляются. [Критерии](WATER_NATIVE_20261013_CONTRACT.md).

## Сохранённые изменения

- AirThermal один раз отвергает заблокированное начало пути вместо
  повторного перебора девяти невозможных получателей. Геометрия,
  теплоёмкости, обмен E/C и четыре транспортных шага прежние.
- WaterConvection проверяет прежний температурный контраст до загрузки
  полных пакетов. Перестановка16 клеток выполняется непересекающимися
  парами с двумя локальными GridCell вместо массива16. Все поля,
  случайные seeds, скорости, фильтры и частоты прежние.
- ParallelSurface прекращает поиск при доказанном отсутствии подходящей
  высоты и не повторяет одинакового донора. Порядок, точный fallback,
  tie-break и бюджеты8/4 сохранены.
- InitializeComponents собирает наличие подвижных твёрдых клеток прямо
  на GPU. При их отсутствии48 пустых Union/Compress проходят с нулевыми
  indirect-размерами; при наличии остаются24 исходные итерации. Полные
  Initialize/Finalize и остальные solid-проходы сохраняются.

JSON веществ, разрешение, расчётные часы, O₂, Q горения, тяга и
визуальные коэффициенты не менялись. GPL-код TPT не переносился.

## Отклонённые варианты и оставшаяся работа

Кэш2048 колонок/256 lanes, групповые RenderComposition-счётчики и
shared-atomic surface-редукции прошли сравнения, но не дали необходимого
ускорения; их код удалён. Увеличение phase-summary кольца не реализовано:
оно отложило бы защитное пробуждение реального перехода. Кольцо3,
fallback и неблокирующее чтение сохранены.

Главная оставшаяся проблема: консервативный phase-fallback включает
дорогие gas/solid-проходы в водяном поле. GPU-проверка убрала только
пустую связность; оставшийся solid-блок всё ещё около3.16мс на вызов.
Далее нужно убирать ненужные полные копии/очистки через доказанную
GPU-классификацию, сохраняя пробуждение настоящего льда/тел и все поля
воды/газа. Само течение, тяжёлая Simulation-проекция и полная цель100FPS
остаются отдельными незавершёнными пунктами. Полный каталог не переаттестован.
