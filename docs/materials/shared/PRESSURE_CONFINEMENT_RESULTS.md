# PC — результаты замкнутого напора и переключателя, 2026-10-07

Физическая база77c346d, ветка codex/gas-motion-and-rendering.
Появившийся во время работы отдельный коммит a7a0d50 с tools/promo сохранён;
эти файлы не менялись. GPU-проверки выполнены на копиях пользовательских
сцен. Сборки проводились только без работающего Phyxel. Реальные числа

## Причина и изменение

Обычный carrier.P содержит потенциал low-Mach тяги и пополняемый игровой
HotAir пара, а не полноценный запас сжимаемого газа. Раньше он нагружал
стенки даже внутри одной открытой полости. Выпуск FJ дополнительно мог
превращать этот потенциал в волну при новом отрыве. Старый a65aaec тоже
обваливал печь: короткая прежняя приёмка не покрывала поздний дефект.

Теперь отдельная связность coarse центров по fine отрезкам различает
замкнутые полости и доступные края air-сетки. Порошки проводят давление,
стенки/жидкости/закрытые air-фильтры перекрывают. Внутри одного компонента
carrier-перепад не разрушает. Между компонентами учитывается избыток
более сильной ЗАМКНУТОЙ стороны; наружное значение служит противодавлением,
не источником сдавливания. Реакционная Wave нагружает и открытые стенки.
Выпуск carrier в Wave только из закрытого источника, без добавки к total P.
Прочности, источник пороха, горение, тепло и алгоритм тяги прежние.

Промежуточный вариант с обеими сырыми поверхностями — FAIL: за240с
754/893 нижних фрагмента. GPU-проба холодной закрытой оболочки
воспроизвела её разрушение наружным carrier100 при внутреннем0 и Wave0.
После правки этот отрицательный контроль проходит; равные P внутри/
снаружи не разрушают, наружная Wave и внутренний избыток при ненулевом
противодавлении по-прежнему разрушают. Порог PC02 не ослаблялся.

В правой панели **«Разрушение (эксп.)»**: по умолчанию выключено,
включая старые сцены без поля PressureDestruction. Запрещает новые отрывы,
сохраняет газовый поток, волны и перенос существующих осколков.
Не восстанавливает стенки и не запрещает тепловое плавление.
Настройка работает без перезапуска, сохраняется настоящим Save action
и его асинхронным снимком. World19/Grid56/Material244 прежние;
scratch связности не сериализуется.
