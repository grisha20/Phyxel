# CG: полоса угля и мерцание, 2026-10-09

Исходная версия 9d26e9b. Отзыв RTX3050: полоса горящего угля, Simulation
около14FPS, Sandbox100; мерцание дыма при35% и ниже сильнее на высоком FPS.
Точная сцена отсутствует. Диагностическая замена: уже горящий слой угля
600°C, 75% ширины поля, глубина height/80, открытые края, два режима.
Это нагрузка для сравнения, не точное воспроизведение пользовательской карты.

Baseline Release4070: 960×540 Simulation/Sandbox combustion1,36/0,17мс;
1920×1080 11,82/0,56мс. На полном поле оба режима теряют физическое время,
Simulation примерно12updates/s. Дополнительная дорогая работа — перенос
конечного кислорода. Не обещать такой же FPS на3050.

Прочитаны паспорта coal/fire/smoke, Phyxel OxidizerTransport/FireGlow/
RenderComposition, TPT COAL.cpp/FIRE.cpp/SMKE.cpp, Air.cpp и Renderer.cpp
render_fire. TPT отображает свежий fire_r/g/b, затем гасит его; у Phyxel
физика60Гц и дополнительные кадры показывают уже погашенное поле.
TPT использует собственную модель горения/воздуха, не наш конечный O₂.
Числа и исходники TPT не переносятся, реальные параметры не назначаются.

До правки: объединить четыре Jacobi итерации мелкого кислородного носителя
в один запуск с halo4 и shared памятью. Сохранить порядок суммирования
right/left/down/up, маски, границы, divergence и число64/1024 итераций.
Проверить побайтно итоговый потенциал, поток и концентрацию. Исходный
путь оставить через PHYXEL_OXYGEN_REFERENCE=1. Private scratch не является
сохранённой физикой. Не сокращать число шагов или качество по FPS.

Для мерцания: сохранить отдельное render-only поле свежего свечения перед
затуханием и читать его во всех промежуточных кадрах. Не менять накопление,
размытие, затухание, физические Grid/O₂/тепло и fixed clocks. Пауза/стирание/
load должны очищать и перестраивать отображаемое поле вместе с исходным.
Тест: после tick кадра повторная композиция без физического шага должна
быть побайтно той же; старый путь обязан показать расхождение. Проверить
30/60/100 кадров, паузу/перестройку, небольшую и плотную дымовую сцену.

Acceptance: GPU equivalence на частичных tiles, закрытых/открытых краях,
преградах/фильтрах и прогретом scratch; profile обоих режимов до/после,
печь обоих режимов и save/load. Готовый bytecode обязателен. Измерения
только своего GPU, нужен повтор Гриши для подтверждения его FPS.
