## Воспроизведение и ограничения

Локальные артефакты (в git не включены):
`artifacts/coal-reheat-20261011/{baseline60,candidate30,candidate60,candidate100}`,
`surface-baseline-fixed`, `surface-candidate`; `run.log`, `measurements.json`,
поля и PNG. Скрипт `replay.ps1` запускает существующий FurnaceSensorVerifier.
Surface включается через `PHYXEL_VERIFY_HANDOFF=1`, `PHYXEL_VERIFY_DRAFT=1`,
`PHYXEL_DRAFT_SURFACE_TRACE=1`; baseline использовал `PHYXEL_DRAFT_BASELINE=1`
(его exit0 сам по себе не PASS — учитывать число failures в журнале).

По просьбе пользователя длинные цикл поддувала300с и filled-hopper600с,
остальные диагностические наборы и обычный12с trace заново не выполнялись.
Их исторические PASS не объявляются новой проверкой этого изменения.
CR01, выбранный CR02 и измеренная стоимость PASS; CR03/остальной CR04
не проверены повторно. Весь паспорт не принят заново.

Это ограниченный игровой лучевой граф: k пока служит коэффициентом связи,
не измеренной излучательной способностью. Размер зерна/время прогрева
не калиброваны в СИ; соответствие реальному времени воспламенения не
установлено. Известная неоднородность fine-O₂ и дальнейшая оптимизация
не закрыты этим исправлением; превосходство над TPT не заявляется.
