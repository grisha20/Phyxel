# GT: объединение записей маски газа

2026-10-08, baseline d091668. Не меняем физические параметры, stencil,
скорости,8подшагов, порядок checkerboard,64-клеточные tiles или их halo.
GasActiveTiles сейчас делает9global atomics на каждую газовую клетку.
Группа16×16 целиком принадлежит одному64×64tile. Сначала собираем наличие
газа в groupshared uint, затем один поток группы пишет прежние9tileбитов.
На плотной группе это сокращает global atomics до256раз; это не обещание
такого же ускорения кадра. Частичные крайние группы проходят оба barrier.

До принятия:12GPU-масок (empty/boundary/sparse/dense ×3размера) точно равны
старой per-cell формуле; существующий GasTileRegressionVerifier сравнивает
полное движение с full scan,2режима×16тиков, Grid/Motion/CellMaterials byte exact.
Измерить отдельную классификацию и настоящий30с кадр печи2560×1440,
физический ход времени1×, газ/воздух/реакции60Hz, тепло20Hz.
Не считать снижение GPU-времени одного прохода доказательством исправления
всех просадок FPS; полный кадр включает вывод, очередь и другие проходы.
