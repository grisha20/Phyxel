# FJ — исправление выброса и движения осколков, 2026-10-07

[Контракт до правки](FRAGMENT_JET_CONTRACT.md),
[исходный дефект SP](STEAM_ROOF_DIAGNOSIS.md). База a65aaec,
ветка codex/gas-motion-and-rendering. Все результаты ниже — новые GPU
прогоны на RTX4070, не прежние PASS. Исходные сохранения не перезаписаны.

## Что изменилось

PressureFracture раньше тормозил даже при нулевом округлённом шаге,
а медленно падающий фрагмент принудительно смещал по диагонали вниз
в свободном воздухе. Теперь торможение обозначает настоящий перекрытый
путь; осыпание вокруг опоры требует действительно заблокированного падения.

Оторванная клетка получает видимый соседний поток с откликом по Mass.
Воздух не читается сквозь твёрдую стенку/селективный фильтр. Перевод скорости
carrier×60, отклик min(4,2.4/Mass)/с и предел180 — игровые числа.
Бросок от накопленного carrier-перепада зависит от напора/массы;
чисто реакционный первоначальный бросок прежний. ID/Mass/T/Lifetime не
заменяются новым порошком. Прочности, JSON, горение, тепло и AirSimulation
не менялись; пороховой pressurePerMass по-прежнему2.

При новом разрушении часть существующего carrier-перепада переводится
в ReactionPulse.X. Total Air.P сохраняется; его carrier-часть становится
меньше на эту же величину при следующем CSInject. Узел объединяет заявки
через max, не сумму пикселей стенки, и ограничивает выпуск положительным
запасом. Противоположный реакционной нагрузке carrier не создаёт обратный
выброс; готовая волна не выдаётся повторно. W/YZ/тепло/масса не добавляются.
Полный механический энергетический баланс этим не заявляется.

## Сохранность тяги и предел сравнения

Новая печь с400 пороха на30с: средняя скорость вверх в трубе
2.809/2.901 (Sandbox/Simulation), влево под котлом2.946/3.360;
оба показателя выше прежнего выбранного порога1. Единицы игровые.

Контроль обычной печи на0/.5/1/2с:12/12 Grid/Air/GasMotion byte comparisons
PASS при одинаковом режиме диагностики activity. Старый шейдер a65aaec
читается через opt-in PHYXEL_FRAGMENT_BASELINE_SHADER, выпуск в baseline
отключён. PHYXEL_SHELL_SYNC_ACTIVITY=1 отключает асинхронный поллинг
phase/combustion-summary для обоих прогонов. Исторический baseline повторён
с теми же текущими остальными обработчиками; файлы old/new хранятся в
matched-before-ordinary/matched-final-ordinary.

Первое сравнение с асинхронным поллингом однажды совпало, следующий прогон
не совпал: уже малая разница температур ведёт к различным пакетам при
кипении. Этот FAIL сохранён в final-ordinary, не объявлен PASS. Совпадение
в контролируемом режиме проверяет физическую правку; полная побайтная
повторяемость игры с асинхронным переключением активности не доказана.

Writer19/Grid56/Material244 прежние. Новый coarse uint scratch выпуска
не сохраняется: результат уже лежит в сохраняемой ReactionPulse.
Исходные SHA256 котла, петарды и печи прежние (SP/PF содержат их значения).

Не приняты: полная EOS закрытого котла, автоматическая pressure-активация
любого нового парового сосуда, баланс обмена механической энергией воздуха
и металла, крупные жёсткие осколки, деформация, все паспорта/все пары.
Старые крошки из сохранения не восстанавливаются в стенку; настоящий
перепад при редактировании может ломать тонкий горячий материал.
