## Воспроизведение и границы

Артефакты: ignored `artifacts/steam-fracture-20261007/`: before, before-long,
trace, flight, edit-thickness. Анализ:
`python Diagnostics/AnalyzeSteamRoof.py artifacts/steam-fracture-20261007`.

Исходная карта: `PHYXEL_VERIFY_PRESSURE_SHELL=1`, `PHYXEL_SHELL_BASELINE=1`,
`PHYXEL_SHELL_SKIP_PROBES=1`, `PHYXEL_SHELL_SCENES=Пар давление`,
`PHYXEL_SHELL_SECONDS=120`; `PHYXEL_ARTIFACT_DIR` задаёт отдельную папку.
Запись первого импульса: `PHYXEL_TRACE_FRACTURE=1`,
`PHYXEL_SHELL_MODE=Simulation`; flight —80с. Контроль редактирования:
`PHYXEL_SHELL_EDIT_PROBES=1` вместо replay сцены. Диагностика читает GPU
только при явно установленном флаге; обычная игра не читает мир ради неё.

Трассирующие и обычный120-секундный replay дали немного разные моменты/
количества (70.30–70.63с;201/208 к120с). Причина точного расхождения не
установлена; детерминизм или матрица30/60/100 этим отчётом не принимаются.
Траектория привязана к возрасту первой группы по сохранённому fragment-clock.

Первая проба редактирования на64×64 была отвергнута: разрушились дальние
концы пластины у края мира; отсутствовал парный контроль без редактирования.
Перенос в128×128 и добавление контроля устранили этот смешанный эффект.
Утверждение о дефекте редактирования по той первой пробе не делается.

Паровая HotAir-ветвь Simulation уже прибавляет игровое давление, которое
общая механика читает после загрузки этого мира. Это не полноценное
термодинамическое давление котла, EOS/насыщение/активация нового парового
сосуда без предыдущей pressure-activity не приняты.
Нужен отдельный этап переноса свободных металлических осколков струёй,
если требуется их дальнейший вынос паром. Желаемый вынос в SP03 пока FAIL.
Автоматически повышать прочность, менять красивую тягу или убирать
разрушение холодных стенок ради этого наблюдения оснований нет.
Паспорта/все материалы/все пары и длительный цикл нового котла не приняты.
