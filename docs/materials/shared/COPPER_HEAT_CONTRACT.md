# CU: расширение проводимости для меди

Дата2026-10-06, записано перед изменением общего кода. Новый материал
использует k2, c.10. До этапа loader допускал k0..1 и внутренний обмен
насыщался при k1; изменение только c не ускоряло однородный стержень,
поскольку общий обмен использует min(Ca,Cb).

Допустить конечный k0..2. Для контакта сохранить прежний коэффициент при
k≤1, а для k>1 ограничить произведение k*fraction симметричным бюджетом, учитывающим максимальный k обоих участников. Для
однородного твёрдого тела k>1 масштабирует скорость внутреннего обмена,
но внутренний бюджет растёт с.20 до.40, а контактный уменьшается с.80 до.60 для пар с k>1; их сумма остаётся≤1. Старые k≤1 проходят
прежнюю формулу. Геометрия преград, излучение, воздух и тяга не меняются.
Энергия переносится симметрично; без новых источников/стоков и без clamp T.

Критерии: CU01–CU06; холодный конец при равных источниках минимум10%
быстрее стали; замкнутые пары/пластина сохраняют Q и диапазон исходных T;
старые сталь/чугун проходят прежние фазовые/тепловые сценарии. Контакт
воды проверяется без изменения её JSON. Это расширение игровой шкалы,
не k СИ. Кипение воды, тяга и горение получают отдельные изменения только
по отдельной задаче.

Промежуточная проверка показала: прежний потолок.20 насыщен при шаге.05с, поэтому первое расширение не ускоряло пластину. Критерий скорости не ослаблен; перераспределён прежний суммарный бюджет1.0 между внутренним и соседним обменом.
