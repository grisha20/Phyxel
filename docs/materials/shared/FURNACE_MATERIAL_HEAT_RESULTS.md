## Что проверено

Все32 ID текущего bundled-каталога:30 физических и2 служебных N/A.
Для каждого физического ID —4 короткие GPU-пробы: непосредственный
FIRE, FIRE через зазор, горячая каменная стенка, горячий carrier.
120 проб PASS по положительной ΔH там, где путь поддержан, конечным
температурам/массе, энергетическому допуску и сохранению массы.
Четыре дополнительные active-regulator пробы heater/cooler PASS.

Это1 секунда фиксированного расчётного времени:20 thermal ticks,
для carrier дополнительно60 обменов. Образец3×3, собственные T0/cp,
масса кисти (для solid density, остальных1); конечный источник2000°C.
FIRE —3 пакета по.2; каменная стенка —3 клетки, её игровые2000°C
допустимы текущей моделью без плавления stone. Зазор до FIRE —9 клеток
от левой поверхности. Carrier имеет конечную ёмкость. Нет постоянно
поддерживаемого термостата/бесплатного Q.

Химия, движение, ambient cooling и регуляторы в этих120 пробах
изолированы; фазы учитываются по энтальпии без смены ID. Это проверка
пути нагрева, не полная реакционная/фазовая приёмка30 веществ в одной
живой печи. Для heater/cooler ниже дополнительно включён настоящий
регулятор: мощность600*.05=30 за шаг, без охлаждения нагревателем
и без нагрева охладителем. Устройства не обязаны вести себя как камень.

## Обнаруженные ограничения и решение

1. Внешний отклик твёрдой поверхности связан с saturate(k), в отличие
   от granular с откликом1. TNT.08 и fuse.02 поэтому получают меньше
   внешнего потока; внутри3×3 ядро прогревается медленнее поверхности.
   Это упрощение модели, не установленная emissivity. Независимые
   оптические/конвективные параметры и масштаб клетки в СИ не калиброваны.
2. Через пустой зазор излучение непосредственно получает solid/granular.
   Для шести жидкостей и шести газов нет такого поглощения: они здесь
   получают тепло контактом и carrier. Отдельно отсутствует прямое
   излучение расплавов; его нельзя считать реализованным по яркому цвету.
3. Плавление реального TNT около80°C в игре не реализовано; исходный
   паспорт явно сообщает это. Различия теплоёмкостей/теплопроводностей
   по температуре и точное время реального прогрева большинства ID
   также не подтверждены этим набором.

Проверка не воспроизвела зависший заряд: он реагирует за3.3..3.4с.
Предварительный кандидат «ускорить внешнее тепло TNT минимум в5раз»
**не реализован и не отмечен PASS**: порог≤12с проходил уже baseline,
нет оснований подменять отсутствие данных удобным сроком взрыва.
Коэффициенты/шейдеры/масса/фазы/тяга и расчётная нагрузка обычной игры прежние.
Длительная новая матрица угля/воды/взрывов не запускалась: физические
изменения отсутствуют. Печь со скриншота не объявляется точным повтором.

## Постоянное правило и запуск

AGENTS.md, WORKFLOW и TEMPLATE теперь требуют FH при добавлении
вещества: прямое пламя/горячий carrier/стенка/зазор, поверхность/ядро,
ΔH/фаза/реакция, времена и ограничения до объявления материала готовым.
Общий набор автоматически включает каждый установленный физический ID;
живой печной сценарий нового ID дополнительно выбирается по его паспорту.
Нагреватель/охладитель и служебные ID отмечаются отдельно.

Запуск из репозитория:
`./Diagnostics/RunFurnaceMaterialHeat.ps1 -ArtifactRoot C:/.../catalog`
и с `-Replay` для сохранённой печи/TNT. Скрипт требует закрытую игру,
сохраняет/восстанавливает диагностические env, не меняет пользовательский save.
