# FI2026-10-08: контракт до кода

Только opt-in flag `progressive-ignition` bit15, fixed self-oxidizing solid с combustion/spreadRate>0, без lifecycle/фаз. Таймер Lifetime увеличивается лишь при положительном расходе, задержка соседнего источника1/spreadRate;8 соседей, нулевой таймер нового источника не может каскадировать за один GPU-dispatch. Начальная клетка может начать от T>300°C, непосредственного огня при T≥100°C, либо собственного фронта. Холодный новый сосед прогревается химическим Q без присвоения300°C. Остывший источник после своей задержки≤100°C сбрасывает ignition. Огню оставляется прежняя аэродинамика; старые вещества не получают flag.

JSON: Mass1, burnRate.5, heat2400, spread4, maximum650; эмиссии smoke.03/CO₂.02/fire2 с flameLifetimeMultiplier.15. Прямой реакционный pressure0. Таймер не занимает BodyId или фазовые поля. Ни новый источник воздушной тяги, ни изменения общих heat/radiation shaders не нужны. До итоговой приёмки критерии FI01..07 из паспорта не ослаблять.

Предохранитель для произвольного spreadRate/большого dt: возраст соседнего источника должен быть также≥2dt, поэтому только что зажжённая клетка не каскадирует при любом положительном dt. Для текущего spread4 этот предел не меняет задержку.
