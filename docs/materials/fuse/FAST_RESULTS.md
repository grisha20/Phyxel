# FU: быстрый почти бездымный фитиль, 2026-10-08

Baseline f61e4ed измерен до изменения физики. [Контракт до кода](FAST_CONTRACT.md).
RTX4070, полный GPU-проход320×180; артефакты `artifacts/tnt-20261008/`
игнорируются Git. Старые [RESULTS](RESULTS.md) относятся к исходному медленному фитилю.

## Причина и изменение

Основной дым давала выгоревшая клетка: обычный Fire затем превращался в Smoke.
Уменьшение прямой smokeRate не убирало этот источник. Теперь фитиль создаёт
короткую скрытую искру fuse_spark→empty; прямые smoke/gas эмиссии отключены.
Пробные.001/.002 давали заметную серую полосу при очень малой массе;
окончательная визуальная проверка показала только короткий огонёк без полосы.
Loader принимает конечный rate0, сохраняя обязательные target ID и верхние границы.
Burn.5→2, spread4→16;
heatPerMass2400/max650 неизменны. Fire→Smoke, уголь, порох, воздух и тяга не менялись.
Трассер сохраняет поджиг; его остаточное Q при удалении не считается замкнутой химией.
