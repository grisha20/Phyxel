# Живое дерево — идея отдельного элемента

Предложение пользователя2026-10-04. Пока не реализовано; в каталог не добавлено.
Обычное дерево остаётся строительным материалом с намоканием и горением.

Живое дерево потребляет доступную воду конечными порциями. Ниже поверхности
распространяются корни; выше — ствол и ветки, затем листья. Плоды, например
яблоки, — следующий объём после проверки самого роста. Без воды рост
прекращается. Стены и соседние конструкции не замещаются ростом.

Перед реализацией составить отдельный паспорт: запас/расход воды, питание,
ограничения размера, направление ветвей и корней, свет/температура,
воздействие огня и масла, сохранение состояния и оба режима. Массу роста
нельзя молча получать только из воды: выбрать явную игровую модель питания.

в текущем этапе их поведение ещё не проверялось.
