## Балансы и ограничения движка

Общая масса клетки = Mass сухого топлива + MoistureMass + FuelMass. Общая энергия учитывает три теплоёмкости и отдельную MoistureEnergy. При смачивании списываются вода/её энтальпия, при сушке они выходят паром; допуск баланса .01%. Lifetime ignition latch снимается; Pressure приземления не хранит воду.

Writer v14, Grid52/Material224; v3–v13 читаются, старый FuelMass=0. В старом wet_charcoal не было запаса воды: он становится coal с предупреждением. Нет комнатной сушки, замерзания влаги или химии смеси.

### WC01a: допустимая жидкость — контракт до правки,2026-10-03

Первый подэтап влажности: coal→wet_charcoal только при контакте с liquid
`core:water` по одной из четырёх граней. Расплав, пар, лёд и диагональная
вода не запускают этот переход. Скорость.35/с, температурные/массовые
параметры и вероятность на тепловом тике20Гц сохраняются.
Общее JSON-правило `contactTransitions.liquid.with` задаёт ID допустимой
жидкости; без with старые внешние материалы сохраняют ANY-liquid семантику.
ID разрешается реестром, не зашивается в шейдер. Несуществующий/non-liquid
with должен отвергаться; core не зависит от внешнего пакета.

До/после: одна диагностика с прежним/новым JSON coal; отдельно прежний
шейдер в изолированном runtime. GPU четырёх граней, диагонали, двух режимов,

при одинаковых контактных тиках. Расплав даёт ровно0 мокрых клеток.
Mass/T сохраняются, вода остаётся без изменений; неподходящий контакт
не сбрасывает ignition latch. Пауза не меняет grid; save/load продолжает
те же контактные шаги. Абсолютная ошибка Mass/тепла≤1e−5 для изолированного
контакта; побитовая проверка неизменной жидкости и неактивных контролей.

Это исправление выбора жидкости, ещё не впитывание массы воды и не сушка.
Новый водный запас, оплаченная сушка и возврат coal — следующий подэтап.
До его реализации мокрый ID остаётся игровым негорючим состоянием;
нельзя выдавать его Mass за массу реально впитанной воды.

Итог WC01a: PASS2026-10-03,1503 проверки; контракт/критерии выше сохранены.

поджигом: их нельзя незаметно отдать влажности. Следующий подэтап должен
ввести отдельное сохранённое состояние воды с переносом вместе с топливом,
