# Медь — `core:copper`

Дата: 2026-10-06. Роль: конструкционный материал, видимая кисть «Медь».
Паспорт и критерии записаны до JSON. Статус этапа: реализовано; CU01–CU06 PASS в выбранном объёме. [Результаты](RESULTS.md).
Задача пользователя: добавить интересный материал после сортировки документов.
Ожидание: медная деталь быстрее стали распространяет тепло, плавится с
оплатой скрытого Q и после охлаждения возвращается именно в медь.

## Источники

- [NIST, отчёт ITS-90](https://pmc.ncbi.nlm.nih.gov/articles/PMC4948925/):
  точка затвердевания чистой меди 1357.77 K = 1084.62 °C.
- [Holme Dodsworth, C103/CW008A](https://holmedodsworth.com/index.php/materials/datasheets/c103-cw008a-of-copper):
  бескислородная медь ≥99.95%; плотность 8.9 г/см³, теплоёмкость 385 Дж/(кг·К),
  теплопроводность при комнатной температуре 393 Вт/(м·К). Это ориентир
  материала, а не перенос чисел СИ в движок. Лист округляет плавление до1083°C.
- [NIST JANAF Cu](https://janaf.nist.gov/tables/Cu-004.html):
  температурная теплоёмкость и энтальпия кристалла/жидкости; постоянные c
  в игре не претендуют на воспроизведение этой таблицы.
- TPT локально: `F:/GitHub/source code the powder toy/simulation/elements/`.
  Поиск COPR/Copper/copper не нашёл отдельной меди. Изучены METL.cpp,
  LAVA.cpp и Simulation.cpp2520–2680: METL неподвижен, HeatConduct251,
  Flammable0, плавится1273K в LAVA; общий переход сохраняет исходный ID
  в ctype, при охлаждении возвращает его. Электропроводность TPT не переносится.
  Хеши локальных файлов зафиксированы в [результатах](RESULTS.md) после проверки.
- Phyxel: [настройка](../../../Materials/core/copper.json),
  [пара расплава](../molten_copper/PASSPORT.md), общие
  [PhaseEnthalpy](../../../Materials/PhaseEnthalpy.cs),
  [ThermalDiffusion](../../../Content/Shaders/ThermalDiffusion.hlsl),
  [BulkThermalGeometry](../../../Content/Shaders/BulkThermalGeometry.hlsli).
  Нового обработчика физики по ID не требуется.

## Взаимодействия и пространства

В обоих режимах контакт с водой/маслом/паром/металлами переносит Q;
каждая металлическая фаза сохраняет свой ID, смешения сплавов нет.
Уголь/дерево/песок не впитывают расплав. Огонь/дым греют по общим
механизмам; тяга и коэффициенты горения прежние. Остальные пары — в
[общей карте](../shared/interaction_pairs.csv), новая химия не объявляется.
Sandbox и Simulation используют ту же фазовую модель; расход O₂ топлива вокруг
отличается по существующему режиму.

Открытая деталь проводит тепло и может плавиться; в сосуде стенка служит
теплообменником, но не огнеупорна. В трубе сплошная стенка ведёт поток по
зазору, а не через металл. Закрытая камера не создаёт испарение меди.
При охлаждении обратное плато требует отвода Q; усадка/прочность не реализованы.

## Балансы и сохранение

hsolid=.10*T+p, hliquid=.50*T+p; L=(.50−.10)*1085=434.0 игровых единиц
на Mass. При1035°C отводимый фазовый Q414.0. Такой L поддерживает единый
нуль энергии, это не реальная теплота плавления. Mass не заменяется density
при фазе. Частичное плавление/затвердевание, температура и ID сохраняются.
Старые сцены получают индексы по стабильным ID; core:metal/steel/cast_iron прежние.
