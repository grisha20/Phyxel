## Энергетический контракт

Сохраняем прежний ноль энергии воды при0°C:
h_water=4.18*T+p, h_ice=2.10*T−333.4+p.
p льда положителен при плавлении; p воды отрицателен при замерзании и
положителен при кипении. При неполном переходе T0°C. Избыток энергии
переходит в новую фазу; обращение внешнего Q возвращает прогресс.

При Mass1 полное плавление льда0°C требует333.4, замерзание воды0°C
отдаёт333.4. Эти числа задают согласованную игровую шкалу относительно
c2.10/4.18 и Lvap2256; клетка не объявляется физическим килограммом.

Исходный этап I использовал scene/worldv11, Grid40/material176.
Текущая версия writer14, Grid52/material244 сохраняет прогресс и BodyId;
этот этап не увеличил структуры. Старыеv3–v10 читаются; отрицательный Lifetime
старого формата или негодного материала отклоняется.

## Взаимодействия и пространство

| Условие | Сейчас / проверка | Неподдерживаемое |
|---|---|---|
| Вода | Обратимый энергетический цикл, Mass сохраняется | Расширение, солёность, переохлаждение |
| Горячий/холодный металл | Парный обмен Q; плавление/замерзание на плато | Полный контракт metal↔molten_metal ещё не выполнен |
| Нагреватель/охладитель | Внешний Q; общие тепловые регрессии повторены | Устройство не меняет фазу без оплаты |
| Огонь | Нагрев без горения льда; отдельной новой огневой матрицы нет | Химические реакции льда не добавлены |
| Открытый объём | FB/BB: свободный лёд поднимается/оседает по плотности среды, наклоняется; после плавления вода течёт | Волны, вращательная инерция, столкновения с импульсом |
| Сосуд/труба | Клеточная пробка; фазовые изменения меняют проходимость | Давление не ломает лёд в SNOW, как особое правило TPT |
| Закрытая камера | Проверены конечный запас Q, энергия и Mass | Давление плавления/разрушение |
| Песочница/Симуляция | Тепловой контракт одинаков; проверены оба режима | Различие режимов относится к воздуху/горению |

## Проверка

До правки определены: остаток энергии≤.01 в минимальных камерах либо
≤.005% для длительного многоклеточного обмена; Mass≤1e−5 относительно.
Проверяются действительные фаза, T, прогресс, обратимость и избыточная Q.
Наличие отдельного PASS не означает приёмки всех пространств и связей.

| ID | Сценарий | Результат 2026-10-03 |
|---|---|---|
| I01 | Частичное/полное плавление и замерзание; обращение и избыток Q | CPU/GPU PASS |
| I02 | Горячий/холодный металл с конечным запасом энергии | GPU PASS; плато0°C, прогресс±202.8 |
| I03 | Частичный переход, пауза/save/load/продолжение | PASS; сохранение и продолжение побитово совпадают |
| I04 | Объединение воды с незавершённым замерзанием | GPU PASS; масса/энергия сохранены |
| I05 | Лёд→вода→пар→вода→лёд | 100 CPU/10 GPU циклов PASS |
