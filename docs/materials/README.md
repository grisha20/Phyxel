## Как устроена папка

```text
docs/materials/
  README.md                индекс материалов
  WORKFLOW.md              порядок работы до реализации
  TEMPLATE.md              шаблон нового паспорта
  steel/
    PASSPORT.md            свойства, источники, модель, критерии и статусы
    README.md              навигация к настройкам, коду и проверкам
  oil/
    PASSPORT.md
    README.md
    OIL_PHASE_CONTRACT.md   контракт конкретного изменения
    OIL_PHASE_RESULTS.md    фактические результаты проверки
  shared/                  механизмы и документы для нескольких материалов
```

Паспорт описывает **реальную физику → TPT → выбранную модель Phyxel**;
неизученные параметры отмечаются «не установлено», неподдерживаемые —
«не реализовано». «Проверено» всегда ссылается на конкретный сценарий.

## Куда добавлять файлы

Для `core:name` создавайте `name/PASSPORT.md`, для другого namespace —
`namespace__name/PASSPORT.md`. Специализированные источники, контракты,
заметки и отчёты храните рядом с паспортом и добавляйте в README папки.
Документ для нескольких материалов хранится один раз в `shared/`;
отчёты общих механизмов/редактора/печей остаются в `docs/` и доступны
через ссылки. Не размножайте копии общего контракта по материалам.

Настройки игры остаются в `Materials/core/*.json`, общие обработчики —
в коде движка. Папка документации даёт ссылки на них. Диагностические
сцены, изображения и логи остаются в игнорируемой `artifacts/`.
