## Контракт

- Ctrl+Z — отмена, Ctrl+Y/Ctrl+Shift+Z — повтор, один шаг по нажатию,
  без повторов от удержания. Обрабатываются в активном окне обычной игры;
  открытое Esc-меню изолирует ввод, файловый перенос блокирует откат.
- Один непрерывный штрих — один снимок до первой команды, а не на каждом
  кадре. Переход на UI/выход с холста завершает штрих по существующим
  правилам кисти. Shift-линия получает запись перед построением при
  отпускании; предпросмотр без построения не добавляет запись.
- Поддержаны материалы, универсальное стирание, температура,
  нагреватели/охладители, все фильтры, прямые линии, очистка сцены и
  перезапуск физики. Физические шаги сами не создают записей истории.
- Восстанавливается полный мир: Grid, Air, GasMotion, Oxidizer,
  AirThermal, ReactionPending, ReactionPulse, Filters. Поэтому отмена
  работающей сцены также откатывает её развитие с момента начала действия.
  Повтор возвращает состояние, которое было непосредственно перед отменой,
  включая развитие физики после штриха; это не повторное исполнение кисти.
- После отмены/повтора мир на паузе. Нажатая кисть/предпросмотр отменяются;
  удержание мыши после отката не рисует повторно. Новое редактирование
  удаляет ветку повтора. Камера, выбранный инструмент и настройки UI
  остаются текущими.
- История только в памяти, до32 записей суммарно undo+redo и256MiB
  их байтовых полей; старые записи вытесняются. При снимке больше лимита
  редактирование разрешено с сообщением, прежняя история сбрасывается,
  чтобы отмена не перескакивала через действие без записи.
- Успешная загрузка, смена масштаба/размера сетки и автоматическое
  расширение холста сбрасывают историю. Сохранение её не сбрасывает.
  История не записывается в .json/.world; ABI/writer17 прежние.
- После восстановления пересоздаются производные маршруты/активность,
  сбрасываются прежняя очередь газовой кисти и накопление отображения.
  Иначе отменённый газ мог снова появляться из отложенного ввода.

отложенного ввода/визуального накопления. Шейдеры и JSON веществ прежние.

## Ограничения и оставшееся

Снимок требует краткого GPU→CPU копирования перед штрихом; удержание кисти
не копирует мир каждый кадр. Лимит относится к хранимым байтовым полям,
дополнительные объекты/текущий снимок/GPU-ресурсы занимают память отдельно.
Штрих без изменения занятых клеток может занимать запись истории.
Снимки не хранят внутренние часы/догадки решателя, поэтому побайтное
восстановление физических полей не означает идентичность всех будущих
траекторий после продолжения. Не проводилась новая полная приёмка
термодинамики/горения всех веществ — изменение относится к редактированию.

Продувание угольного слоя обсуждено как следующий игровой механизм:
воздух с сопротивлением проходит между зёрнами, доставляет кислород
глубже. В этом этапе проницаемость и химия угля не менялись.
