## Результат

Категория «Фильтры» содержит десять отдельных кистей с индивидуальными
рисунками: пар, вода, масло, газы, жидкости, порошки, выбранный вид,
стенка, только воздух, без воздуха. Названия карточек целиком, на двух
строках; наведение даёт пояснение. Справа показана выбранная кисть.
Материальная карточка снова выбирает обычную кисть вещества; для exact-ID
после этого выбирается «Выбранный вид». Прокрутка колесом и стрелками.
Иконки выполнены средствами существующего SpriteBatch, без новых bitmap.

ЛКМ наносит только в свободные клетки. Защищены все активные пакеты,
в том числе невидимый газ малой массы, и уже существующий фильтр.
ПКМ снимает слой, не меняя пакеты. Для замены требуется сначала снять слой.
Проверка занятости копирует только bounding-строки штриха в отдельный
staging buffer; capture сохранения использует свой буфер.

| Кисть | Частицы | Фоновый воздух/O₂ |
|---|---|---|
| Стенка | Задерживает все | Задерживает |
| Только воздух | Задерживает все | Пропускает |
| Без воздуха | Пропускает все, включая подвижные тела | Задерживает |

Теплопроводность остаётся разрешённой. Фазы и химические параметры не
менялись. Writer17 добавляет AllParticles bit21, сохраняя структуру хвоста
карты v16. Чтение v3–v16 сохраняется; прежние ID и flags имеют прежний смысл.
Каталог материалов 23/276 пар и Grid56/Material244/probe24 не изменены.

## Источник и оставшиеся границы

Прочитаны локальные TPT SimulationData.cpp GetWallTypes, Simulation.cpp
IsWallBlocking1080–1097, Air.cpp карты bmap. Источник расположен
в F:/GitHub/source code the powder toy; соответствие установленному exe
не подтверждено. SHA256 SimulationData.cpp:
74B90E93D0D32BBE6F308C9EA1DABB4ED2A61A3EBF9DFB5091D4D2BFE9E94EED.
Роли WALL/AIRONLY/AIRBLOCK воспроизведены для каналов Phyxel; это не
утверждение полной совместимости с TPT. Числа в СИ не назначались.

EWALL, DETECTOR, FAN, ABSORB, CONDUCTOR, EHOLE, GRAVITY, STASIS и прочие
устройства отложены пользователем. ENERGY WALL требует отсутствующего
класса энергетических частиц TYPE_ENERGY; FIRE не выдаётся за этот класс.
Неподвижные материалы не начинают двигаться от разрешающего фильтра.
Поровый запас едет вместе с разрешённым зерном; состав внутри пакета
не фильтруется отдельно. Загруженный пакет или смена фазы могут оставить
запрещённый вид внутри слоя, его состояние сохраняется. Тепловые стенки,
произвольные составные правила и пипетка слоя остаются будущими этапами.
