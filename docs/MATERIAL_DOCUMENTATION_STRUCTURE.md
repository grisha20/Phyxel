# Структура документации материалов — 2026-10-06

Материалам выделены отдельные папки; точка входа —
[каталог](materials/README.md). Для `core:steel` паспорт находится в
[steel/PASSPORT.md](materials/steel/PASSPORT.md), для `core:coal` —
[coal/PASSPORT.md](materials/coal/PASSPORT.md).

В папке материала:

- `PASSPORT.md` — реальные свойства с источниками, поведение TPT,
  текущая/целевая модель Phyxel, критерии, результаты и ограничения.
- `README.md` — назначение файлов и ссылки на игровой JSON, паспорт,
  специализированные документы и общий код регистрации.
- Контракты, отчёты и заметки одного материала/семейства — рядом;
  например, [папка масла](materials/oil/README.md).

В [shared](materials/shared/README.md) — общие механизмы, источники,
план, карта взаимодействий, CSV пар и архив прежнего индекса.
Отчёты общих механизмов движка, печей и редактора остаются в `docs/`
и доступны из паспортов. Общие документы не дублируются.
JSON, шейдеры, диагностический код и игнорируемые артефакты остаются
на прежних местах; их назначение не смешивается с паспортом.

Правило «источники → паспорт → реализация → измерение → обновление»
сохранено. В [шаблоне](materials/TEMPLATE.md) явно перечислены
смачивание, впитывание, проницаемость, вязкость/текучесть по температуре,
плотность/плавучесть, тепло, фазовые переходы, поджиг/горение/тушение,
взаимодействия, режимы и пространства. Неприменимые и неизученные
свойства помечаются отдельно; неизвестные числа не выдумываются.

- Локальные Markdown-ссылки и ссылки evidence ведут к существующим файлам.
- Сравнение хешей подтверждает неизменность кода, JSON и ресурсов игры.
- `git diff --check` проходит. Новые сборки/физические прогоны не требуются:
  этап меняет организацию документов, а не поведение материалов.

Наличие паспортов всего каталога не означает, что все реальные свойства

неподдерживаемые механизмы остались с прежним смыслом.
