Изучен локальный TPT: `F:/GitHub/source code the powder toy/gui/game/`.
В `GameView.cpp` `UpdateDrawMode` выбирает `DrawLine` по Shift;
обработчик отпускания вызывает `GameController.DrawLine`, а рендер
до отпускания — `Brush.RenderLine`. `GameController.cpp` передаёт
линию выбранному инструменту. Phyxel использует эту последовательность
жеста с собственной сеткой, радиусом кисти и GPU-командой Segment.

## Контракт

- Esc в обычной игре открывает/закрывает меню. Незавершённая линия
  отменяется. Диагностические режимы сохраняют Esc для аварийной отмены.
- Меню останавливает физические шаги, блокирует кисть, панораму, колесо
  и фоновые кнопки. Состояние обычной паузы независимо от меню;
  закрытие не запускает мир, который ранее стоял на паузе.
- «Сохранить сцену…» выбирает файл и использует штатный GPU capture и
  writer17. «Загрузить» использует штатную загрузку. Меню остаётся открыто,
  показывает результат и запрещает перекрывающиеся файловые операции.
  Выход через меню требует «Выйти без сохранения»; незавершённая файловая
  операция блокирует это подтверждение.
- Shift должен быть нажат в начале жеста. ЛКМ тянет произвольную прямую;
  полоса и кольца показывают выбранный радиус. Ни одной команды построения
  до отпускания нет. Материал, режим, правило фильтра, радиус и плотность
  фиксируются в начале, поэтому отпускание Shift не меняет уже начатый жест.
- Shift + ПКМ — прямое стирание частиц и фильтров. Фильтры и материалы
  сохраняют существующие правила защиты занятых клеток. Физика не менялась.
- Уход на UI/с холста, потеря фокуса, изменение отображаемых границ мира,
  Esc или сохранение/загрузка отменяют предпросмотр. После отмены с зажатой
  кнопкой новый жест начинается только после отпускания. Клик «Продолжить»
  и удержание этой кнопки мыши не попадают в мир.
