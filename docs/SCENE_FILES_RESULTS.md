Кнопки «Сохранить» и «Загрузить» открывают выбор файла `.json`.
`Ctrl+S` сохраняет в последний успешно выбранный файл текущего запуска;
при первом сохранении тоже открывается выбор. `Ctrl+Shift+S` — выбор другого
файла, `Ctrl+L` — загрузка. После операции в нижней строке виден путь;
раньше сообщения сохранения/ошибок не выводились вообще.

Формат прежний: рядом с JSON лежит одноимённый `.world`. Переносить сцену
нужно обоими файлами. Старый путь `%LOCALAPPDATA%/Phyxel/scene.json`
продолжает использоваться при запуске; последний выбранный путь между
запусками пока не запоминается. Writer13/Grid48 и физика не изменены.

Во время диалога симуляция приостановлена, прежняя пауза восстанавливается.
Отмена не запускает запись/загрузку. Ошибка не меняет путь быстрого
сохранения; параллельные запросы не перебивают незавершённую операцию.
Сериализуемые настройки фиксируются вместе с запросом снимка GPU:
последующее переключение режима не подменяет режим сохранённого снимка.
Сообщение помещается в доступную ширину; неподдерживаемые шрифтом знаки
имени файла заменяются вопросительными знаками только при отображении.
