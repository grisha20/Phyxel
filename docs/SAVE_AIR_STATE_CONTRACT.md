# Сохранение перегретого воздуха — 2026-10-05

Приоритет пользователя: сначала восстановить сохранение; нагрев печи и
горение угля исследовать позже по новой пользовательской сцене. Исходная
сцена закрыта, есть только снимок `Invalid air energy/capacity`.

Текущее ограничение кодека: воздух хранит два float (абсолютная энергия,
теплоёмкость), но отклоняется при E/C > 5273.16 K. Перенос воздуха может
оставлять тепло при очень малой теплоёмкости, поэтому этот предел не
является инвариантом GPU. Это отдельная проблема динамики, а не повреждение
двоичного представления. Предел температуры частиц не определяет предел
температуры переносимого поля воздуха.

Цель этого этапа: сохранять и загружать конечные неотрицательные E/C
без верхнего температурного порога и без изменения энергии/теплоёмкости.
Сохраняются проверки размеров, NaN/Infinity, отрицательных запасов,
ненулевой энергии при нулевой теплоёмкости и переполнения E/C. Формат v17
не меняется. Состояние сохраняется для воспроизведения ошибки физики,
успешная запись не означает исправления переноса тепла или горения.

До исправления воспроизвести отказ настоящим GPU-переносом между двумя
соседними узлами с T=300/5000 K, C=1, скоростью 4, замкнутыми связями.
Один шаг оставляет конечную E/C выше старого порога. После исправления
реальный игровой путь Save As должен создать пару JSON/world, Load должен
восстановить байты AirThermal точно, повторный Save — сохранить их снова.
Также проверить старые сохранения, повреждённые поля, отмену диалога,
быстрое сохранение и сохранение расширенной сцены существующими проверками.

Физика и коэффициенты веществ на этом этапе не меняются. TPT Air.cpp
использует поле температуры hv; его формат не переносится на E/C Phyxel.
Причина перегрева в исходной пользовательской сцене пока не установлена.

E/C=115960350 K. Игровой Save As отказал с той же ошибкой. Это контрольный
случай, а не восстановленная пользовательская печь.

**41 PASS**, 11 обращений к выбору пути; точное disk/GPU восстановление

поля сохраняются побайтно, неверные/неконечные поля по-прежнему отклоняются,
поддерживаемые исторические форматы читаются. Debug build: 0 ошибок и
предупреждений. Нативный ответ диалога в автоматизации подменён, игровые
обработчики, GPU capture и файловая запись настоящие.
