# Первый вертикальный тизер Phyxel

Согласованный сюжет: «Начал с воды — дошёл до бомбы». Русский ролик для
Shorts/TikTok, 1080×1920, 30 кадров/с, 27,2 секунды. Интерфейс игры показан
отдельно целиком, палитра материалов дополнительно увеличена.

## Сценарий

| Время | Кадры | Текст/смысл |
|---|---|---|
| 0–3,6 с | Вода из записи 16 июля | Начал с воды |
| 3,6–6,6 с | Огонь из записи 3 октября | Добавил огонь |
| 6,6–9,6 с | Полный интерфейс и палитра со скриншота | Выбираешь материалы |
| 9,6–12,6 с | Скриншот печки | Собрал печку |
| 12,6–14,6 с | Скриншот потоков воздуха | Движение газов |
| 14,6–18 с | Первая бомба из записи 7 октября | А потом… |
| 18–23,6 с | Вторая бомба из записи 7 октября | И вот что вышло |
| 23,6–27,2 с | Phyxel и затухающий огонь | Что проверить следующим? |

Записи с окном The Powder Toy не использованы. Ролик показывает реальные
видео и скриншоты владельца; рисунок фона, музыка и монтажные звуковые
эффекты созданы скриптом. Игровое видео ускорено/замедлено в двух сценах,
точные значения сохранены в manifest; это монтаж, а не изменение симуляции.
Для скриншотов печки и потоков используется плавное приближение.

Озвучка первой версии — установленный русский голос Windows Microsoft
Irina Desktop. Это пробная синтетическая озвучка, которую можно заменить
записью автора. Использованы локальные шрифты Arial без включения файлов
шрифта в репозиторий или папку передачи.

## Воспроизведение монтажа

Нужны Python с Pillow/NumPy, FFmpeg, Windows с Arial и Microsoft Irina Desktop.

```powershell
python tools/promo/render.py --source 'D:\Видео\Desktop' --output 'D:\Видео\Phyxel_Promo'
```

При необходимости укажите `--ffmpeg 'C:\ffmpeg\bin\ffmpeg.exe'`.
`--silent-voice` позволяет собрать вариант без SAPI. Список исходников,
обрезки, скорость, длительность и надписи заданы в `render.py`.
Исходные записи не изменяются. Генерируемые видео и WAV храните вне Git
или в игнорируемом каталоге `artifacts/`.

Результаты:

- `Phyxel_Shorts_RU_v1.mp4` — H.264/AAC, версия с голосом;
- `Phyxel_Shorts_no_voice_v1.mp4` — те же кадры с музыкой/эффектами без голоса;
- `Phyxel_Resolve_timeline.xml` — FCP 7 XML с восемью отдельными готовыми
  сценами и сведённым звуком, подготовленный для импорта в Resolve;
- `edit_manifest.json` — исходники, временные отметки и геометрия монтажа;
- `work/` — готовые сцены, графика, голосовые фразы и звук.

XML ссылается на `work/` абсолютными file URL. При перемещении папки нужно
перепривязать медиа. Текст и обрезка уже включены в каждую сцену; для их
изменения отредактируйте скрипт и пересоберите ролик. В CapCut можно импортировать
готовый MP4 либо отдельные `work/shot_*.mp4` и `work/mix.wav`.
Сырые исходники и скриншоты нужно сохранить для дальнейших вариантов.

## Проверка первой версии, 2026-10-07

- Экспорт: 1080×1920, 30 FPS, 27,2 с, H.264, AAC stereo 48 kHz.
- Обе версии полностью декодированы FFmpeg без ошибок.
- Восемь сцен проверены на контактном листе: читаемые основные надписи,
  интерфейс целиком, увеличенные материалы, печка, потоки, две сцены бомбы.
- XML проверен как документ и по длительности/непрерывности сцен;
  фактический импорт в редактор ещё не проверен.
- Прослушивание и художественная оценка голоса остаются за автором;
  техническая проверка звука не заменяет прослушивание.

Видео, превью и рабочие файлы находятся в `D:\Видео\Phyxel_Promo` и в Git
не включены. Скрипты и этот сценарий сохранены отдельно от изменений физики.
