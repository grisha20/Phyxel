# Первый вертикальный тизер Phyxel

## Вторая версия по примерам автора, 2026-10-07

После просмотра первого варианта автор попросил более живой мужской голос,
динамичный монтаж и плавные переходы. Два ролика `video_2026-10-07_22-42-45.mp4`
и `video_2026-10-07_22-42-49.mp4` использованы как образцы подачи: кадры игры
на весь экран, короткие надписи поверх действия, смена масштаба и планов.
Кадры/голоса/музыка из этих примеров не включены в результат.
От платной подписки Runway автор отказался; дальнейший этап использует
только бесплатные инструменты. Платные генерации не запускались.

`Phyxel_Shorts_RU_v2.mp4`: 1080×1920, 30 FPS, 18,9 с, 11 сцен. Основной
эксперимент занимает вертикальный кадр, интерфейс показан целиком в двух
сценах, печка и потоки — со скриншотов. Камера приближается внутри планов,
переходы занимают 5 кадров. В начале короткий намёк на финальную бомбу;
финальная бомба показана с полным интерфейсом. Надписи сменяются по словам
речи. В конце — название и вопрос зрителю. Музыка/монтажные эффекты синтезированы
скриптом, без использования сторонних песен.

Получены три мужские нейросетевые фразы через
[официальную демоверсию Chatterbox Multilingual](https://huggingface.co/spaces/ResembleAI/Chatterbox-Multilingual-TTS):

1. «Я начал с воды. А дошёл до этого!»
2. «Делаю свою физическую песочницу. Тут можно рисовать материалы и сразу проверять, что получится.»
3. «Добавил огонь, нагрев и движение газов.»

Поддержка русского и лицензия MIT указаны в
[репозитории разработчика](https://github.com/resemble-ai/chatterbox).
Выбран русский мужской образец, предоставленный самой демоверсией;
голоса авторов присланных роликов не клонировались.
Лицензия модели MIT не подтверждает отдельно права на демонстрационную
запись голоса: вторая версия является пробой для просмотра, а разрешение
на рекламную публикацию с этим конкретным голосом пока не установлено.
Происхождение зафиксировано в `neural_voice/voice_provenance.json` вне Git.
Следующие запросы к демо вернули ошибки без пояснения; доступность и квоты
не гарантируются. Уже полученные WAV используются повторно без обращения к сервису.

Субтитры выровнены локально по временам слов
[Vosk](https://alphacephei.com/vosk/models) с русской моделью
`vosk-model-small-ru-0.22` (Apache 2.0). Аудио для этого никуда не отправляется.
25 из 27 слов совпали с распознаванием; два слова получили интерполированные
времена, исходный авторский текст сохранён. Это проверка времён слов, а не
замена прослушивания. Подробности — `dynamic_work/recognition.json` вне Git.

```powershell
python tools/promo/cloud_voice_demo.py --output 'D:\Видео\Phyxel_Promo\neural_voice' --limit 3
python tools/promo/render_dynamic.py --source 'D:\Видео\Desktop' --output 'D:\Видео\Phyxel_Promo' --voice 'D:\Видео\Phyxel_Promo\neural_voice'
python tools/promo/align_words.py --work 'D:\Видео\Phyxel_Promo\dynamic_work' --model 'D:\PhyxelPromoCache\vosk-model-small-ru-0.22'
python tools/promo/render_dynamic.py --source 'D:\Видео\Desktop' --output 'D:\Видео\Phyxel_Promo' --voice 'D:\Видео\Phyxel_Promo\neural_voice' --words 'D:\Видео\Phyxel_Promo\dynamic_work\words.json'
```

Для первых двух/последнего шага нужны Pillow/NumPy и FFmpeg; для выравнивания —
отдельная среда с Vosk. На Windows модель Vosk должна находиться в пути
без кириллицы; итоговые файлы могут лежать в исходной русской папке.
Для воспроизведения достаточно сохранённых трёх WAV: демо вызывается только
при отсутствии файла. Сценарий поддерживает и расширенную версию с шестью
фразами, но получение следующих трёх через демо не подтверждено.

Альтернатива для автономной озвучки — `neural_voice.py` с отдельной средой
Chatterbox и CUDA PyTorch. Загрузка многогигабайтных зависимостей/весов была
остановлена после получения онлайн-пробы; локальная озвучка не установлена
и не проверена. Скрипт подготовлен по документированному API, а не выдан
за работающую установленную систему. Незавершённые загрузки весов удалены;
модели распознавания и остальные рабочие файлы находятся вне репозитория.

Видео, графика, звук, отчёты и модели не коммитятся. Проверки второго экспорта:
полное декодирование, формат/длительность, контактный лист всех 11 сцен,
непрерывность монтажа и уровень звука. Файлы лежат в `D:\Видео\Phyxel_Promo`.

## Первая версия

Согласованный сюжет: «Начал с воды — дошёл до бомбы». Русский ролик для
Shorts/TikTok, 1080×1920, 30 кадров/с, 27,2 секунды. Интерфейс игры показан
отдельно целиком, палитра материалов дополнительно увеличена.

## Сценарий

| Время | Кадры | Текст/смысл |
|---|---|---|
| 0–3,6 с | Вода из записи 16 июля | Начал с воды |
| 3,6–6,6 с | Огонь из записи 3 октября | Добавил огонь |
| 6,6–9,6 с | Полный интерфейс и палитра со скриншота | Выбираешь материалы |
| 9,6–12,6 с | Скриншот печки | Собрал печку |
| 12,6–14,6 с | Скриншот потоков воздуха | Движение газов |
| 14,6–18 с | Первая бомба из записи 7 октября | А потом… |
| 18–23,6 с | Вторая бомба из записи 7 октября | И вот что вышло |
| 23,6–27,2 с | Phyxel и затухающий огонь | Что проверить следующим? |

Записи с окном The Powder Toy не использованы. Ролик показывает реальные
видео и скриншоты владельца; рисунок фона, музыка и монтажные звуковые
эффекты созданы скриптом. Игровое видео ускорено/замедлено в двух сценах,
точные значения сохранены в manifest; это монтаж, а не изменение симуляции.
Для скриншотов печки и потоков используется плавное приближение.

Озвучка первой версии — установленный русский голос Windows Microsoft
Irina Desktop. Это пробная синтетическая озвучка, которую можно заменить
записью автора. Использованы локальные шрифты Arial без включения файлов
шрифта в репозиторий или папку передачи.

## Воспроизведение монтажа

Нужны Python с Pillow/NumPy, FFmpeg, Windows с Arial и Microsoft Irina Desktop.

```powershell
python tools/promo/render.py --source 'D:\Видео\Desktop' --output 'D:\Видео\Phyxel_Promo'
```

При необходимости укажите `--ffmpeg 'C:\ffmpeg\bin\ffmpeg.exe'`.
`--silent-voice` позволяет собрать вариант без SAPI. Список исходников,
обрезки, скорость, длительность и надписи заданы в `render.py`.
Исходные записи не изменяются. Генерируемые видео и WAV храните вне Git
или в игнорируемом каталоге `artifacts/`.

Результаты:

- `Phyxel_Shorts_RU_v1.mp4` — H.264/AAC, версия с голосом;
- `Phyxel_Shorts_no_voice_v1.mp4` — те же кадры с музыкой/эффектами без голоса;
- `Phyxel_Resolve_timeline.xml` — FCP 7 XML с восемью отдельными готовыми
  сценами и сведённым звуком, подготовленный для импорта в Resolve;
- `edit_manifest.json` — исходники, временные отметки и геометрия монтажа;
- `work/` — готовые сцены, графика, голосовые фразы и звук.

XML ссылается на `work/` абсолютными file URL. При перемещении папки нужно
перепривязать медиа. Текст и обрезка уже включены в каждую сцену; для их
изменения отредактируйте скрипт и пересоберите ролик. В CapCut можно импортировать
готовый MP4 либо отдельные `work/shot_*.mp4` и `work/mix.wav`.
Сырые исходники и скриншоты нужно сохранить для дальнейших вариантов.

## Проверка первой версии, 2026-10-07

- Экспорт: 1080×1920, 30 FPS, 27,2 с, H.264, AAC stereo 48 kHz.
- Обе версии полностью декодированы FFmpeg без ошибок.
- Восемь сцен проверены на контактном листе: читаемые основные надписи,
  интерфейс целиком, увеличенные материалы, печка, потоки, две сцены бомбы.
- XML проверен как документ и по длительности/непрерывности сцен;
  фактический импорт в редактор ещё не проверен.
- Прослушивание и художественная оценка голоса остаются за автором;
  техническая проверка звука не заменяет прослушивание.

Видео, превью и рабочие файлы находятся в `D:\Видео\Phyxel_Promo` и в Git
не включены. Скрипты и этот сценарий сохранены отдельно от изменений физики.
